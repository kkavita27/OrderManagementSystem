Error: OrderManagementSystem.entity.OrderItem' has no identifier (every '@Entity' class must declare or inherit at least one '@Id' or '@EmbeddedId' property)
Solution: This error occurs in JPA/Hibernate when an entity class—in this case, OrderManagementSystem.entity.OrderItem—is marked with the @Entity annotation
but lacks a field designated as the primary key.
Add an ID field to your class and annotate it with @Id. Use @GeneratedValue if you want the database to handle the ID creation.
In OrderItem class -
 @Id //import jakarta.persistence.Id;
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    //GenerationType.IDENTITY tells the JPA provider (like Hibernate) to let the database handle the primary key generation using an auto-increment column.Instead of the Java application calculating the next ID, it sends the record to the database without one.
    private Long itemId;
