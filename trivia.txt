1. @SpringBootApplication is a meta annotation that enables the auto configuration, component scanning, java based configuration, allowing Spring Boot applications to start with minimal setup.
It combines three important annotations into one: @Configuration, @EnableAutoConfiguration, @ComponentScan.
ComponentScan - Automatically scans for bean.
Configuration - @Configuration tells Spring: this class knows how to create objects (beans); trust it and manage them for me.The MOST IMPORTANT, the @Configuration
It makes beans SINGLETON-safe. Spring creates only ONE object, even if you call it many times.
EnableAutoConfiguration - used when you want to full manual control, you define your own @Configuration & You explicitly control component scanning
public static void main(String[] args) {
Application start point
Spring Boot creates an ApplicationContext.
@SpringBootApplication → includes @EnableAutoConfiguration.
This tells Spring Boot:
Go and apply all possible auto-configuration classes.

2. IN pom.xml - added starter dependency, the purpose of starter dependency is by adding this dependency in xml, you will get list of dependencies readily available
to use in your applications, you can focus more on business logic and use these feature in your project.
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-web</artifactId>
</dependency>

This automatically includes:
Spring MVC
Embedded Tomcat
Jackson (JSON)
Validation
Logging

-Starters do not contain code.
-They only contain dependencies
-Auto-configuration uses those dependencies to configure beans

Spring Boot supports both application.yml and application.properties. If both are present, no error occurs, but properties defined in application.properties take precedence over application.yml.
